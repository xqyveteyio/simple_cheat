# Simple Cheat

Minecraft 1.20.1 的纯客户端 Fabric 模组，用来降低单人游戏难度。目前实现了「杀戮光环」（KillAura）。

服务端不需要安装。

## 环境要求

- Minecraft 1.20.1
- Fabric Loader 0.15.0 或更高
- [Fabric API](https://modrinth.com/mod/fabric-api) 0.92.x（1.20.1 版本）
- Java 17 或更高

## 安装

1. 用 [Fabric 安装器](https://fabricmc.net/use/installer/)为 1.20.1 安装 Fabric Loader。
2. 把 Fabric API 的 jar 放进 `.minecraft/mods/`。
3. 把 `build/libs/simple-cheat-1.0.0.jar` 也放进 `.minecraft/mods/`（不要放 `-sources.jar`）。

## 按键

| 按键 | 作用 |
| --- | --- |
| `R` | 开关杀戮光环 |
| `B` | 开关远程防护 |
| `右 Shift` | 打开设置界面 |

两个按键都可以在游戏内「选项 - 控制 - 按键绑定」的 Simple Cheat 分类里改。

设置界面里：左键点模块名切换开关，右键点模块名展开设置；开关类设置左键点击切换，多选类设置左键下一项、右键上一项，数值类设置左右拖动滑条。鼠标悬停在设置上时，面板底部会显示该项的说明。所有改动在关闭界面时自动存到 `.minecraft/config/simple-cheat.json`。

## 杀戮光环设置

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 攻击距离 | 4.0 | 眼睛到目标碰撞箱的距离，原版手动攻击是 3.0 |
| 攻击节奏 | 等待冷却 | 等待冷却每次都是满伤害；固定 CPS 更快但每下伤害低 |
| 每秒攻击次数 | 8 | 仅固定 CPS 节奏下生效 |
| 目标优先级 | 距离最近 | 可选距离最近、血量最低、视线最近 |
| 同时攻击多个目标 | 关 | 开启后一 tick 内攻击多个目标，代价是每下都不满伤害 |
| 转向方式 | 静默转向 | 静默转向只把朝向发给服务端，你的视角不会动；也可以选择不转向或真实转动视角 |
| 跳过无敌帧目标 | 开 | 见下方说明 |
| 需要视线 | 开 | 关闭后可以隔墙攻击 |
| 挥手动画 | 开 | 关掉只是没有动作，伤害照常 |
| 打开界面时暂停 | 开 | 打开背包、箱子时停止攻击，聊天框除外 |
| 使用物品时暂停 | 开 | 吃东西、拉弓、举盾时不攻击 |

目标类型分别有独立开关：敌对生物（默认开）、动物、玩家、村民与傀儡、已驯服的生物、盔甲架、其他生物（默认都关）。玩家目标会自动跳过同队玩家和创造/旁观模式的玩家。

### 关于无敌帧

原版里生物挨打后有 0.5 秒无敌帧，期间同等伤害的攻击会被 `LivingEntity#damage` 直接判定为无效，既不掉血也不击退。所以提高 CPS 并不能提高实际输出或击退频率，击退频率的上限就是每秒 2 次。

「跳过无敌帧目标」会在攻击前检查目标的 `hurtTime`，正处在无敌帧里就跳过，把这次攻击让给别的目标。配合「同时攻击多个目标」，面对一群怪时会自动轮着打而不是把攻击浪费在同一只身上。

顺带一提，「固定 CPS」在打单个生物时几乎总是比「等待冷却」差。攻击伤害要乘以冷却进度系数 `0.2 + h² × 0.8`，以钻石剑为例，等待冷却约 11.2 DPS，固定 8 CPS 只有约 3.2 DPS，而且拿不到冲刺攻击的额外击退（那需要冷却进度超过 0.9）。它主要适合一击能秒杀的场合，比如刷怪塔里清小怪。

## 远程防护设置

对付骷髅、女巫、恶魂这类远程敌人。需要手上有盾牌，优先用副手的，副手没有才用主手。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 举盾方式 | 检测到威胁时 | 常驻举盾会让移动速度只剩 20% 且无法冲刺，一般不建议 |
| 投射物飞来时 | 开 | 检测速度方向指向你的箭、火球、药水 |
| 敌人瞄准时 | 开 | 骷髅拉弓、掠夺者装填弩时就提前举盾 |
| 附近有远程敌人时 | 关 | 范围内有远程敌人就举盾，最保险但最影响移动 |
| 威胁检测距离 | 24 | 在多远范围内寻找威胁 |
| 自动面向威胁 | 开 | 盾牌只挡面朝的半边，用静默转向对准，不动你的视角 |
| 威胁解除后保持 | 10 | 单位 tick，避免盾牌频繁开合 |
| 优先击杀远程敌人 | 开 | 让杀戮光环把进入攻击范围的远程敌人排到最前面 |

### 盾牌的几个硬限制

这些都是原版机制，模组绕不过去：

- 举盾后要满 5 tick（0.25 秒）才真正生效，所以必须提前预判，这就是「敌人瞄准时」这个选项存在的原因——骷髅拉满弓要 20 tick，提前量足够。
- 盾牌只挡面朝的那半边（`blockedByShield` 里对朝向做点积判断），而且判断用的是服务端记录的朝向，所以「自动面向威胁」实际是靠静默转向实现的。
- 穿透附魔的弩箭直接无视盾牌。
- 拿斧头的敌人攻击有概率破盾，破盾后盾牌进入 5 秒冷却，这期间模块不会尝试举盾。

### 为什么能边举盾边攻击

原版举盾时不能攻击，是客户端在 `MinecraftClient.handleInputEvents` 里把左键事件空转吃掉了，服务端并不检查这个。杀戮光环直接调 `interactionManager.attackEntity`，不走那段输入处理，所以两个模块可以同时工作。

相应地，杀戮光环的「使用物品时暂停」对举盾开了例外：吃东西、拉弓时照常暂停，举盾时不暂停。

## 构建

```bash
./gradlew build
```

产物在 `build/libs/`。

开发时直接启动带模组的游戏：

```bash
./gradlew runClient
```

## 添加新模块

1. 在 `module/` 下新建一个类继承 `Module`，在构造函数里调用 `addSettings(...)` 注册设置项，重写 `onTick()` 写逻辑。
2. 在 `ModuleManager` 的构造函数里把它加进 `modules` 列表。

按键绑定、配置存取、设置界面、HUD 显示都会自动接上，不需要额外改动。

## 注意

这是个作弊模组，只建议在单人存档或自己的服务器上用。多数联机服务器禁止这类模组，可能会被封禁。
